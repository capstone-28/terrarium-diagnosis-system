# MQTT 브로커 실행 및 통신 점검 (Windows)
Windows에 Mosquitto와 Python 3.9 이상(py 실행기 포함)을 설치하고 mosquitto를 PATH에 등록한다.
최초 1회 CMD에서 아래 명령으로 점검 도구의 의존성을 설치한다.

    py -3 -m pip install "paho-mqtt>=2.1,<3"

1. start_broker.bat로 브로커를 실행하고 창을 열어 둔다. 기본 포트는 1883이다.
2. test_broker.bat를 실행한다. 테스트 구독 승인 후 별도 발행자가 diagnostics/terrarium/ 아래의 고유 토픽에 식별값을 발행한다. 같은 값이 수신되면 PASS와 발행~수신 소요 시간을 출력한다. 실패 시 단계와 오류를 출력한다. 단계별 대기 제한은 5초이다. 장비와 백엔드 없이 실행 가능하다.
3. subscribe_all.bat를 실행한 상태에서 ESP32를 연결한다. terrarium/terrarium_01/+/+의 토픽과 UTF-8 메시지 본문을 화면에 표시하고, PC의 현지 수신 시각과 함께 logs/YYYY-MM-DD.jsonl에 누적한다. 날짜는 수신 시점 기준이며 한 줄이 메시지 한 건이다. Ctrl+C로 종료한다. 연결이 복구되면 재구독한다. 구독이 끊겼던 구간의 기록에는 공백이 생길 수 있다.

두 도구는 기본적으로 같은 PC(127.0.0.1)의 브로커에 접속한다. 다른 PC의 브로커를 사용하면 CMD에서 주소와 포트를 인자로 전달한다.

    test_broker.bat 192.168.0.10 1883
    subscribe_all.bat 192.168.0.10 1883

테스트 전용 토픽은 테라리움 구독 범위 밖에 있다. DB 저장 여부는 백엔드에서 확인한다.

## 노드·토픽별 수신 통계
reception_stats.bat를 실행하면 오늘의 수신 로그를 분석한다. 이전 날짜는 CMD에서 reception_stats.bat 2026-11-19처럼 지정한다.
최초·마지막 수신 시각과 그 사이 경과 시간, 노드별 메시지 종류별 건수, 연속 heartbeat 사이의 최대 간격을 표시한다.
수신 경과 시간에는 기록기를 시작한 후 첫 메시지를 기다리거나 마지막 메시지 이후 대기한 시간은 포함되지 않는다.
